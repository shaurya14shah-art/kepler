How Kepler decides

Every alert is a typed decision from purpose-trained statistical models, so it's cheap to run, gives the same answer every time, and shows its reasoning.

Learns normal

Weekly and time-of-day baselines per metric and per slice (platform, region, …), trained on your history.

Weighs the evidence

Exact statistical tests and pooled evidence windows, plus a filter that learns from your 👍 / 👎 labels.

Explains where

Root-cause drilldown tells you which segment broke, with a confidence you can trust and act on.

Fits the tools you already use

Pull metrics from Prometheus, Datadog, New Relic, CloudWatch, PostHog, Mixpanel, Amplitude, Sentry or Postgres; receive data from OpenTelemetry, Segment or a simple push API; send incidents to Slack, PagerDuty, email, Grafana, Datadog or a signed webhook.

Web dashboard

Overview, metric charts with expected ranges, incidents, models, integrations and settings.

Terminal app

The same features full-screen in your terminal, plus a CLI for every action and shell completion.

Three detection models

Orbit (fast, shared), Area (trained per metric and slice) and Time (catches slow burns), all included.

Kepler AI, built in

An assistant that runs on your machine: ask about your metrics in plain English, and it can also do maths and formal proofs, answer general questions from a local knowledge library with sources, and write it all up as a typeset PDF.

Deterministic and private

Trained intent models, exact computer algebra and retrieval from datasets you choose. No hosted language model, nothing sent to us. Optional Wikipedia lookups send only the words of a question, and can be turned off.

Install

Kepler runs on your own server or laptop (macOS or Linux, Python 3.11+), or anywhere Docker runs.

Python package

pip install kepler_watchdog-1.0.0-py3-none-any.whl
kepler serve

Opens on http://127.0.0.1:8000 and prints your dashboard sign-in key.

Docker

docker compose up -d
docker compose logs kepler   # sign-in key

Data lives in a volume; the container runs as a non-root user.

Questions

Does Kepler send my data anywhere?

No. Kepler runs on your servers and has no telemetry. It only contacts the tools you connect it to (for example Slack for alerts), and Wikipedia for general-knowledge questions if you leave that on. See the privacy policy.

Is it really free?

Yes, during early access every feature is free, and Kepler has no way to charge you: billing is switched off.

Is Kepler AI a chatbot like ChatGPT?

No. It's built from trained classifiers, rules and exact computer algebra, plus a local search over datasets you choose. It's predictable and private, and it tells you when it doesn't know.

What do I need to run it?

macOS or Linux with Python 3.11 or newer, or Docker. A small server is enough for most teams.
